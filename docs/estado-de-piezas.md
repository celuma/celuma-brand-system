# Estado de las piezas

Los lienzos son un catálogo de conceptos y variantes. Ningún artboard queda aprobado para distribución por aparecer aquí. Antes de preparar una publicación, una firma o un impreso, Rafael y la persona responsable de marca deben elegir la variante y validar el texto y el medio.

| Grupo | Uso actual | Validación pendiente |
| --- | --- | --- |
| Fundamentos | Referencia de identidad | Archivo maestro del logotipo y reglas de uso |
| Papelería corporativa | Explorar variantes | Elegir variante y preparar medidas, sangrado, tintas y archivos de imprenta |
| Documentos clínicos | Solo concepto visual | El membrete corresponde al laboratorio cliente según ADR 0002; validar cualquier huella de plataforma |
| Etiquetas de laboratorio | Solo exploración | Especificación de impresora, identificadores y pruebas físicas |
| Material digital y presentaciones | Inspiración visual | Confirmar capacidades, cifras, afirmaciones y nombres antes de publicar |
| Componentes | Inventario | Documentar y verificar cada patrón con la app real |
| Propuesta · Reglas de identidad (Fundamentos) | Propuesta pendiente de aprobación | Validar roles de color, escalas, estado del logotipo, iconos y voz |
| Propuesta · Publicaciones A, B y C (Material digital) | Propuesta; A recomendada | Elegir dirección y preparar plantillas editables |
| Propuesta · Fichas de componentes | Propuesta de referencia | Validar con quien responde por UI/UX; no sustituye al código del frontend |

Las maquetas heredadas contienen nombres de instituciones y afirmaciones de producto o normativas sin respaldo confirmado. No deben copiarse a material público. Para publicaciones nuevas use nombres ficticios, cifras claramente ilustrativas y textos validados. Los informes clínicos y las etiquetas requieren revisión de producto además de revisión gráfica.

Las propuestas nuevas están marcadas con “Propuesta” en la sección, el artboard y la pieza. Ver [la revisión gráfica](revision-grafica-y-direccion-de-marca.md) y [la guía de publicaciones](guia-de-publicaciones.md).
