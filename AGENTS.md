# Agent instructions — celuma-brand-system

## Scope

This repository contains the Céluma visual system and reusable presentation assets. Preserve established tokens, components, logos, typography, and clinical tone across outputs.

## Validation

- Inspect the affected HTML, JSX, CSS, and exported assets together.
- Check that changed assets render correctly at their intended size and on light/dark backgrounds where applicable.
- Record manual review because this repository currently has no checked-in automated build or PR workflow.

## Safety boundaries

1. Use synthetic copy and images only. Never add PHI, secrets, credentials, customer exports, or real clinical reports.
2. Do not reinterpret logos or tokens silently; document deliberate brand-system changes.
3. Do not overwrite source-quality assets with lower-resolution exports.
4. Do not commit, push, merge, tag, or publish unless Rafael explicitly requests that exact action.
